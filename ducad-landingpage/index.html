One workflow

From first sketch to a part you can trust

Geometry, analysis, documentation and automation share one document — so a changed dimension flows through all of them.

Solid modeling

Real B-rep solids, built from parameters

Not a polygon mesh: exact surfaces from the OpenCASCADE kernel. Every dimension can be a named parameter, so one edit regenerates the whole part.

  • Extrude, revolve, loft, sweep, helix, boolean, pattern, mirror, split
  • Fillet (constant or variable), chamfer, draft, and shell that opens any face to a set depth
  • ISO hole wizard M2–M12: clearance, tapped, counterbore, countersink
  • ISO fasteners and bearings from the toolbox, with cosmetic or cut threads
  • PBR materials and studio lighting, with SSAO and contact shadows
SimulationNew

Know if it holds before you cut metal

A finite-element solver ships inside the app. Fix a face, apply a load, press run — the stress field paints straight onto your model.

  • Linear static stress, natural frequencies, linear buckling, steady-state heat and thermal stress
  • Loads: force, pressure, torque, gravity, bearing and remote load
  • Hex voxel mesh by default, quadratic tetrahedra for curved parts
  • Mass, center of mass and inertia tensor per body and per assembly

Results are engineering estimates (about ±10 % on the default mesh), not certification numbers.

AI agentNew

An agent that models, measures and answers

Open the AI Chat sidebar and ask in plain language. The agent uses the same tools you do — it inspects geometry, runs checks and edits the model in front of you.

  • Works with Claude, OpenAI-compatible providers, or a local CLI agent such as Claude Code
  • One agent batch is one undo step; risky edits arrive as a green/red preview you accept or reject
  • Failed operations come back with a specific cause and fixes that were verified by dry run
  • On-device only by default — external AI is strictly opt-in
Drawings

Manufacturing drawings, generated from the model

One click turns the solid into an ISO sheet: projected views, a section, dimensions, a bill of materials and numbered balloons.

  • A0–A4 sheets with ISO 5457 border and title block
  • Top, front, side, isometric, section and detail views with hidden-line removal
  • ISO 286 fits and GD&T annotations, plus tolerance stack-up checks
  • Vector PDF, SVG and DXF export

Everything included

The rest of the toolbox

Sheet metalNew

Base flange, edge flange, hem and jog with bend radius and k-factor. Unfold to a flat pattern and export DXF with bend lines on their own layers.

ConfigurationsNew

Variants of one design: parameter overrides, suppressed features, material swaps, CSV design tables.

Tolerances & GD&TNew

ISO 286 fits, GD&T symbols on the sheet, worst-case or RSS stack-up.

Standard partsNew

ISO 4762 and 4014 bolts, nuts, washers, pins and ball bearings, listed in the BOM by standard.

Design checks

Requirements written as data — mass, wall thickness, clearance, peak stress — re-evaluated after every change.

Vector and pencil input

Draw Bézier paths with fills and layers, or sketch freehand with Apple Pencil — strokes are recognized as lines, arcs and circles, constrained, and extruded straight to 3D in their own colors.

Constraint sketching

Lines, arcs, ellipses, polygons, slots, splines and text, held by a geometric and dimensional constraint solver with tiered snapping.

Assemblies

Mates, interference checks, gear, screw and rack couplings, sequenced exploded views.

Parametric history

A searchable feature tree. Edit an early step and everything downstream regenerates.

Open formats

STEP in and out. Export STL, OBJ, GLB, SVG, PDF and DXF. The native .ducad file is plain JSON.

Design as code

The same engine, without the window

Every modeling step is a JSON operation in a replayable log. That makes a part something you can diff, review, test in CI and hand to an agent.

  • ducad-cliRun, inspect, check, render, simulate and build from the terminal.
  • MCP server27 tools over stdio. With --attach the agent drives the open app, where you watch each step.
  • Git-friendlyOne operation per line, plus geometric diffs that show added and removed volume.
  • Hardware CIA deterministic build writes STEP, STL, PDF, PNG and BOM. A failed check stops it.

Why DuCAD

Built to be owned, not rented

An open kernel

OpenCASCADE is a mature open-source B-rep kernel. No kernel license, no seat fee.

Files you can read

Designs are JSON and STEP. Nothing is locked in a proprietary container.

Private by default

Your geometry stays on your device. Network AI and the agent bridge are off until you turn them on.

Free software

Rust from the sketch solver to the renderer, released under AGPL-3.0.

Get Started

Build it from source

  • Stable Rust toolchain via rustup
  • CMake 3.16 or newer and a C++17 compiler, to build the OpenCASCADE kernel
  • macOS on Apple Silicon and iPadOS are the primary targets; Linux is built and tested in CI

The first build compiles OpenCASCADE (about 8–15 minutes) and caches it in target/. Later builds are fast.

terminal 
git clone --recurse-submodules https://github.com/cmjcode/ducad.git
cd ducad/ducad-editor

# Run the application
cargo run -p ducad-app

# Install the CLI and MCP server for agents
make install-agent-tools
