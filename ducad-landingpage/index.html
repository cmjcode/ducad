Core Capabilities

One app, one complete workflow — from sketch to manufacturing

From precise 2D sketches to production-ready technical drawings — every stage of engineering design lives in one consistent workflow.

01 · 2D Sketching

Parametric 2D sketching & precision geometry

A complete sketching toolkit with a self-contained geometric/dimensional constraint solver, tiered smart snapping, and interactive curve editing — the precision foundation for every 3D model built on top.

  • Full entity set: Line, Rectangle, Circle, Arc (Center-Radius & 3-Point), Ellipse, N-sided Regular Polygon, Slot
  • Construction lines (X) for reference geometry without breaking closed-profile detection
  • 2D sketch text — TrueType/OpenType fonts vectorized into extrudable curves
  • Smart tiered snapping: Endpoint → Midpoint → Center → Intersection → Grid
  • Levenberg-Marquardt constraint solver: Coincident, Parallel, Perpendicular, Tangent, Symmetric, Equal, Distance, Radius, Angle
  • Trim, Extend, bi-arc parallel Offset, and symmetric Mirror
02 · 3D Solid Modeling

Industrial-grade 3D B-Rep solid modeling

Powered by the OpenCASCADE (OCCT) kernel — one of the most mature open-source B-Rep kernels in the industry — not a polygon mesh, so every model is precise and manufacturing-ready.

  • Extrude (Blind, Symmetric, Up to Face), custom 3D-axis Revolve, multi-profile Loft, path Sweep
  • Helix/Spring/Coil geometry for springs, bolt threads, and auger blades
  • Boolean Union, Cut, and Intersect
  • Constant & variable-radius Fillet, Chamfer, thin-wall Shell, Draft Angle
  • 3D Emboss/Deboss text on planar faces
  • ISO-standard Hole Wizard: Simple, Counterbore, Countersink, Tapped (M2–M12)
03 · Shell & Direct Modeling

Thin-wall Shell & intuitive face operations

Hollow out solids with uniform wall thickness and perform push-pull direct modeling on any planar or curved face in real time.

  • Thin-Wall Shell / Hollow — create hollow enclosures with customizable wall thickness
  • Face selection context bar — instant access to Sketsa di Face, Revolve, Helix, Rib, Draft Angle, and Split Face
  • Datum Workplanes — Offset, Angled, and 3-Point reference planes at any 3D coordinate
  • Real-time face push-pull and smart boolean cut detection
04 · Parametric History

Dependency-graph-based parametric history

Every design step is recorded as a node in a traceable, editable, regenerable Directed Acyclic Graph (DAG) — not just a linear undo list.

  • Full Feature Tree & History with quick feature search
  • Edit a past feature's parameters → all downstream geometry regenerates automatically
  • Per-operation history (Extrude, Cut Face, Shell, Push-Pull, etc.) with timestamps
05 · 2D Technical Drawings

Production-ready 2D technical drawings & BOM

Generate standardized multi-view engineering drawings from 3D models with ISO/ANSI layouts, cross-section hatching, automated dimensions, and Bill of Materials (BOM) tables.

  • Standard paper formats: A0–A4 (Portrait & Landscape) with ISO 5457 engineering border & title block
  • Multi-view orthographic projection: Top, Front, Right side, and 3D Isometric views
  • Section View (A-A) with automatic ISO/ANSI cross-hatching and Hidden Line Removal (HLR)
  • Detail View callouts with customizable zoom ratios (2:1, 4:1, 5:1)
  • Integrated Bill of Materials (BOM) table and associative technical dimensions
  • High-resolution vector PDF & SVG export ready for manufacturing

Why DuCAD

Industrial-grade capability, without the licensing trap

DuCAD is built as a modern alternative to proprietary CAD — adopting a real, industrial-class B-Rep kernel without million-dollar licensing fees or monthly subscriptions.

Aspect AutoCAD Shapr3D DuCAD
Solid modeling kernel Autodesk ShapeManager (ACIS-derived) Siemens Parasolid (proprietary) OpenCASCADE (OCCT) — genuine open-source B-Rep
Kernel licensing cost Bundled into expensive Autodesk licensing Bundled into the Shapr3D subscription No kernel licensing cost
2D technical drawings Strong industry standard, included Paid add-on (≈$38/month) Fully included, no extra cost
Data storage & privacy Proprietary (.dwg) + Autodesk Cloud Proprietary (.shapr) + cloud sync Open formats (.ducad, STEP, DXF) — 100% offline
Stack & runtime performance Decades-old monolithic C++, heavy RAM (~1.5–3GB) Swift + C++ (Parasolid), macOS/iOS-centric 100% modern Rust, memory-safe, RAM <150MB, startup <1s
Direct modeling (push/pull) Separate commands (PRESSPULL/EXTRUDE/SUBTRACT) Automatic Adaptive Push/Pull Smart Boolean Cut Detection — real-time overlap detection

Interoperability

  • STEP (.step, .stp) — international standard B-Rep CAD model

Export

  • STEP (.step, .stp) — full B-Rep solid for CNC/CAM

  • SVG (.svg) — 2D vector for laser cutting & CNC routers

  • STL, OBJ, PLY, 3MF — mesh formats for 3D printing / slicers

Under the Hood

Multi-crate workspace architecture

Built modularly across 8 Rust crates — each layer isolated with a clear responsibility.

ducad-coreDocument model, undo/redo, assembly tree, mates, units
ducad-sketch2D sketch engine, constraint solver, snapping, region solver
ducad-kernelOpenCASCADE B-Rep wrapper: boolean, fillet, hole, helix, section
ducad-renderwgpu engine: 3D camera, PBR shaders, SSAO, grid, sketch overlay
ducad-ioImport/export for STEP, GLB/GLTF, SVG, PDF, DXF, STL, OBJ
ducad-uiegui components: toolbar, context bar, HUD, drawing sheet, drawers
ducad-i18nLocalization & translation dictionaries for 18+ languages
ducad-appMain application, winit/eframe event loop, window management

Get Started

Run DuCAD from source in minutes

  • Latest stable Rust Toolchain (1.75+) via rustup
  • CMake ≥ 3.16 and a C++17 compiler (Clang/GCC/MSVC) to build the OCCT kernel
  • macOS (Apple Silicon & Intel), Linux (X11/Wayland), or Windows 10/11

The first build compiles OpenCASCADE from source (~8–15 minutes) and is cached permanently in target/ — subsequent builds are instant.

terminal 
git clone https://github.com/cmjcode/ducad.git
cd DUCAD

# Run the application
cargo run -p ducad-app

# Run unit & integration tests
cargo test --workspace
