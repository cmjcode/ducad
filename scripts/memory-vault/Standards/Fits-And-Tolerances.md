# Suaian dan Toleransi (ISO 286, sistem lubang dasar H7)

Acuan cepat untuk memilih suaian poros terhadap lubang H7. Nilai dalam
mikrometer (µm), deviasi atas/bawah. Periksa terhadap ISO 286-2 sebelum
dipakai untuk produksi.

| Rentang Ø (mm) | H7 (lubang) | g6 (poros) | h6 (poros) | k6 (poros) | p6 (poros) |
|---|---|---|---|---|---|
| 3–6 | +12 / 0 | −4 / −12 | 0 / −8 | +9 / +1 | +20 / +12 |
| 6–10 | +15 / 0 | −5 / −14 | 0 / −9 | +10 / +1 | +24 / +15 |
| 10–18 | +18 / 0 | −6 / −17 | 0 / −11 | +12 / +1 | +29 / +18 |
| 18–30 | +21 / 0 | −7 / −20 | 0 / −13 | +15 / +2 | +35 / +22 |
| 30–50 | +25 / 0 | −9 / −25 | 0 / −16 | +18 / +2 | +42 / +26 |

| Suaian | Sifat | Contoh pemakaian |
|---|---|---|
| H7/g6 | longgar, berputar/geser presisi | pin pemandu, poros gigi |
| H7/h6 | geser pas (bisa dirakit tangan) | locating pin, spigot |
| H7/k6 | transisi | hub pada poros dengan pasak |
| H7/p6 | sesak (press fit) | bushing, bearing housing |

Catatan untuk DUCAD: model CAD biasanya dibuat pada ukuran nominal; toleransi
ditulis di gambar kerja. Untuk cetak FDM, suaian ini tidak berlaku — lihat
`Design-Rules-FDM.md`.
