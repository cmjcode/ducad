# Preferensi Default

Semua butir di bawah adalah **default awal, boleh diubah user**. Bila user
menyatakan preferensi lain, perbarui butir terkait (jangan menumpuk
duplikat) dan tulis alasannya.

- Satuan: mm (sudut dalam derajat). — default awal, boleh diubah user
- Toleransi umum: ±0,1 mm. — default awal, boleh diubah user
- Fillet default tepi luar: R1. — default awal, boleh diubah user
- Tebal dinding minimum FDM: 1,2 mm. — default awal, boleh diubah user
- Tebal dinding minimum CNC aluminium: 1,0 mm. — default awal, boleh diubah user
- Lubang baut default: clearance normal (`{"iso":"M…"}` tanpa `kind`). — default awal, boleh diubah user
